# QUARZA

**Explore the world of quartz through an immersive 3D experience.**

QUARZA is an interactive web experience focused on quartz and its different varieties. The project combines cinematic scroll animations, interactive 3D models and a minimal interface to create a more visual and engaging way to explore minerals.

Instead of being a traditional mineral catalog, QUARZA uses the website itself as part of the experience. As you scroll, the crystal moves, rotates, changes scale and interacts with the content around it.

## ✦ Features

* Immersive scroll-driven animations
* Interactive 3D quartz models
* Collection of different quartz varieties
* Detailed mineral information
* Side-by-side mineral comparison
* Smooth camera and object transitions
* Minimal and responsive interface
* Mobile-friendly experience

## ✦ Tech Stack

Built with:

* Next.js
* React
* TypeScript
* Three.js
* React Three Fiber
* GSAP
* Tailwind CSS

## ✦ Concept

The main goal of QUARZA is to make mineral exploration feel less like reading a database and more like interacting with an object.

The experience is built around three main sections:

**Story** — a cinematic journey through the properties and structure of quartz.

**3D Explorer** — an interactive space where users can rotate, zoom and inspect different minerals.

**Collection** — a visual library containing different quartz varieties and their characteristics.

## ✦ Status

New minerals, 3D models, animations and interactive features will be added as the project evolves.
